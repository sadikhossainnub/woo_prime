Connects WooCommerce to ERPNext for real-time Pricing Rules evaluation and Loyalty Points balance & redemption.

== Description ==
Woo Prime Connector is a lightweight WordPress plugin that connects your WooCommerce store to ERPNext in real-time.

Features:
1. Real-time Pricing Rules: Evaluates ERPNext Pricing Rules (Volume discounts, Tiered pricing, Customer Group discounts) dynamically in WooCommerce Cart.
2. Loyalty Points Balance & Redemption: Displays ERPNext Customer Loyalty Points balance on Checkout page and allows instant point redemption.
3. Easy Settings Page: Set your ERPNext URL in WooCommerce -> Woo Prime ERPNext settings.

== Installation ==
1. Upload the `woo-prime-connector` folder to `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to WooCommerce -> Woo Prime ERPNext and enter your ERPNext Site URL.
